**Transforming raw public transit data into geospatial intelligence for the German capital.**

## 📌 Project Overview
Berlin operates one of Europe's most intricate transit networks. This project processes the **GTFS (General Transit Feed Specification)** from VBB (Verkehrsverbund Berlin-Brandenburg), handling over 400MB of schedule data to solve a core urban mobility question: *Where are the supply bottlenecks during peak demand?*

## 🛠️ Tech Stack
* **Qlik Sense Cloud**
* **Qlik Scripting Language** (Advanced ETL & Data Transformation)
* **Set Analysis** (For real-time, complex aggregations)
* **GeoAnalytics** (Stop density and spatial mapping)

## 💡 Key Business Insights
1. **Peak Hour Volume:** Precise identification of trip departures at 08:00 AM across the Berlin-Brandenburg region.
2. **High-Frequency Corridors (Busy Routes):** A dynamic ranking of routes with the highest operational density (e.g., M10, U7, S41 Ringbahn).
3. **Multimodal Connectivity:** Agency grouping and mapping (BVG, S-Bahn, DB) to analyze intermodal integration.

## 🚀 Key Technical Challenges Overcome
* **Data Modeling:** Built a relational model optimized for GTFS standards.
* **Encoding & Localization:** Resolved UTF-8 character issues for German localized strings (Umlauts).
* **UI/UX Design:** Developed a high-contrast Dark Mode dashboard for a "Command Center" experience, utilizing Layout Containers for custom positioning.
